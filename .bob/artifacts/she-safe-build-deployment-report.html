Deployment to https://safegaurd-women-safety.vercel.app
⚠️ The Vercel project and GitHub repository at the existing domain were not accessible from this workspace. The application is fully built locally. Deployment must be performed manually using the steps below to avoid creating a new project.
A
Via existing GitHub repo (recommended)
Push to the repo connected to the existing Vercel project. Vercel auto-deploys and preserves the domain. Run: git remote add origin <YOUR_REPO_URL> → git push origin main
B
Via Vercel CLI linked to existing project
Run vercel login → vercel link --project safegaurd-women-safety → vercel --prod. Select the existing project when prompted — do NOT create new.
C
Via Vercel Dashboard drag-and-drop
Run npm run build, then drag the dist/ folder into the existing project's deploy panel on vercel.com.
✅ vercel.json is included with SPA rewrites (all routes → index.html) and security headers. No additional Vercel configuration needed.

Built-in Safety Disclaimers
All safety-sensitive features include clear in-app disclaimers:
  • SOS screen clearly states emergency services are NOT automatically contacted — call 112 directly
  • Contact notifications labeled "Pending" without SMS backend configuration
  • Map risk data labeled "SIMULATED DATA"
  • Demo Mode banner on every simulation — "No real emergency services contacted"
  • Fake Call labeled with yellow "SIMULATED CALL" warning bar
  • Audio recording: clearly states it stays in browser until backend configured
  • Travel background timer: clearly states app must remain open
